# 客诉智能分类与处理建议系统

基于真实服务运营经验搭建的客诉智能分析工具。上传客诉工单CSV，自动完成分类、优先级评估、情绪分析、处理建议生成及批量异常检测。

## 功能

- **自动分类**：关键词规则引擎，5个分类（退款/物流/商品质量/服务态度/其他）
- **优先级评估**：P0紧急 / P1重要 / P2普通 三级，综合情绪+关键词+金额
- **情绪分析**：愤怒/焦虑/平静
- **处理建议**：自动生成可执行话术和操作指引
- **批量异常检测**：自动识别相似客诉聚集，预警批量风险
- **可视化看板**：分类饼图、优先级柱状图、情绪分布、交叉热力图

## 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 启动
streamlit run app.py
```

打开 http://localhost:8501 即可使用。
